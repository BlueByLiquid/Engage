# Engage

## Star Trek: The Next Generation — Rewatch Guide

A searchable, spoiler-light guide to **all 176 episodes** of *Star Trek: The Next Generation*, with an individual description and viewing recommendation for each episode. Made for fans revisiting the series with someone who wants the highlights without the roughest episodes.

### [🚀 Open the interactive TNG Rewatch Guide](https://bluebyliquid.github.io/Engage/)

**If the link isn't live yet:** GitHub Pages needs to be enabled once in the repository settings. The complete guide is already saved as [index.html](./index.html).

### What's included

- **Must Watch:** Classics and essential story development.
- **Worth Watching:** Strong episodes that are worth the time.
- **Borderline:** Mixed or divisive episodes, with reasons to include or skip them.
- **Skip:** Episodes safe to miss.
- Search episodes, filter by season, choose viewing modes, and mark watched episodes. Progress is saved in the browser.

### Publish the webpage on GitHub Pages

1. Go to **[Settings → Pages](https://github.com/BlueByLiquid/Engage/settings/pages)**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select **main** and **/(root)**, then press **Save**.
4. When deployment finishes, visit **[bluebyliquid.github.io/Engage](https://bluebyliquid.github.io/Engage/)**.

The README is shown automatically on the repository's GitHub home page. GitHub Pages hosts the actual interactive website from `index.html`; simply viewing that file in GitHub shows source code rather than the rendered site.
